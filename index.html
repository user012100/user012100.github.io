Ali Salifov is a web designer and a web developer. His practice spans across digital design and print design, exploring the relationship between visual systems and culture. Through websites, editorial projects and identity design, he creates work that treats design as both a functional tool and a space for expression.

  2. Gossip uses the Are.na API to build a gossip-themed website that transforms a curated archive into an interactive interface. Click to view.

  3. Persistence of Color curates three readings as a digital binding on a website, involving sketching in code and developing a design system. Click to view.

  4. Cult of the Ugly is a collaborative project responding to Cult of the Ugly by Steven Heller as a web page, involving cooperative sketching, pair programming and creating a print layout. Click to view.

  5. Thoughts on Interaction of Color is a project responding to Chapter 16 of Interaction of Color by Josef Albers, involving typesetting and replying to the text as a web page. Click to view.
