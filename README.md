# [Typography & Interaction Index](https://user012100.github.io)

Works by *Ali Salifov*, a web designer and web developer. His practice spans across digital design and print design, exploring the relationship between visual systems and culture. Through websites, editorial projects and identity design, he creates work that treats design as both a functional tool and a space for expression.

[user012100.github.io](https://user012100.github.io)

## Projects

### [[untold]](https://user012100.github.io/functions)
A dedicated space for creative writing, whether it's poetry, lyrics, or anything in between.

### [Gossip](https://user012100.github.io/links)
Uses the Are.na API to build a gossip-themed website that transforms a curated archive into an interactive interface.

### [Persistence of Color](https://user012100.github.io/binding)
Curates three readings as a digital binding on a website, involving sketching in code and developing a design system.

### [Cult of the Ugly](https://user012100.github.io/spread)
A collaborative project responding to *Cult of the Ugly* by Steven Heller as a web page, involving cooperative sketching, pair programming, and creating a print layout.

### [Thoughts on Interaction of Color](https://user012100.github.io/manuscript)
A project responding to Chapter 16 of *Interaction of Color* by Josef Albers, involving typesetting and replying to the text as a web page.
